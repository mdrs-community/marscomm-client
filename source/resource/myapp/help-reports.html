Mission Reports

The Reports panel lists all the daily and special reports for the current Sol (mission day). Each report represents a formal written communication — crew members on Mars write reports and transmit them to Mission Control on Earth, where they can be reviewed and approved.

Who Can See Which Reports?

Each report type may be restricted to specific roles or groups. If you do not have access to a particular report, it will not appear in your panel. For example, a Medical report may only be visible to the Medical Officer and Mission Control Medical staff. If you believe you should see a report that is missing, contact your mission coordinator.

Report States

Every report goes through a series of states as it is written, transmitted, and reviewed. The color of the report name indicates its current state:

Color State Meaning
Orange TODO The report exists but has no content yet. It needs to be written.
Blue Populated Content has been written and saved, but not yet transmitted to the other planet.
Purple Transmitted / In Transit The report has been transmitted and is traveling across the communications delay. A progress circle shows how much time remains.
Teal Received The report has arrived at the other planet and can be read there.
Red Rejected Mission Control has reviewed the report and rejected it (did not approve it).
Green Approved Mission Control has reviewed and approved the report.

Writing a Report

Click the Edit button next to a report name to open the rich-text editor. The editor will pre-fill with a standard template if the report is currently empty. You can format text using the editor toolbar (bold, italic, font size, color, etc.).

You can also paste plain text directly into a report using the Paste button (the clipboard icon), which reads from your system clipboard without opening the full editor. This is useful for pasting in text prepared elsewhere.

The Copy button (the copy icon) copies the current report content to your clipboard so you can paste it into another application.

Attachments

You can attach files to a report using the file picker button in the report row. Multiple files can be selected at once. Once attached, the attachment count is shown on the 00 button (the number reflects how many attachments the report has). Clicking that button opens the Attachment Manager, where you can view, download, or delete individual attachments.

Transmitting a Report

When your report is ready, click Transmit to send it to the other planet. The report will travel across the one-way communications delay (the same delay that applies to chat messages). A circular progress indicator shows the transmission in progress. Once it arrives, Mission Control on Earth can read it.

You can only transmit a report from the current Sol, and only from your own planet. You cannot transmit a report that you are viewing from a past Sol.

Approving a Report (Mission Control only)

When a transmitted report arrives at Earth, Mission Control staff can check the Approve checkbox to mark it as approved. Checking or unchecking this box updates the report state immediately (no separate transmit step needed for approval status — it is communicated separately).

Resetting a Report (Mission Control only)

The Reset button is available to Mission Control staff on the current Sol. It clears all content, attachments, and state from the report on both planets, returning it to the empty TODO state. A confirmation prompt will appear before the reset is applied. This is intended for training exercises and debugging — use with caution during a real mission.

Navigating Past Sols

Use the Sol spinner in the top bar to navigate to any previous Sol and read its reports. When viewing a past Sol, editing and transmitting are disabled — reports are read-only for historical Sols.

Note: The communications delay applies to report transmission just like chat messages. Once a report is transmitted, it cannot be recalled or edited during transit. Plan accordingly.
